# Scope and Releases

## V1 — Production foundation
Required:
- organization, workspace, department, project hierarchy
- users, invitations, memberships, RBAC + scoped permissions
- form studio with versioning, reusable fields/components, tables/repeating groups
- submission runtime with draft/autosave/validation
- schedule engine and generated task occurrences
- task inbox and status lifecycle
- configurable approval workflows
- immutable audit trail
- master data registries
- attachments/object storage
- notifications: in-app + email adapter
- PDF/XLSX/CSV export
- Excel import/mapping wizard foundation
- reporting datasets and standard dashboards
- Domain Pack install/upgrade/uninstall framework
- Oil & Gas starter pack
- API documentation and webhooks
- observability, backups, migrations, test suite

## V1.5
- advanced report builder
- richer automation designer
- comments/mentions
- configurable signatures
- external guest/client portal
- domain pack marketplace/catalog UX
- improved template migration tools

## V2
- offline-first/PWA synchronization
- mobile applications if justified
- AI-assisted form/template generation
- AI Excel-to-form mapping
- anomaly detection and narrative summaries
- more industrial packs
- enterprise SSO/SAML/SCIM
- data warehouse/analytics connectors

## Explicitly out of initial V1
- arbitrary executable customer code
- custom customer forks
- full ERP/CMMS replacement
- real-time SCADA control
- safety-critical automated control actions
