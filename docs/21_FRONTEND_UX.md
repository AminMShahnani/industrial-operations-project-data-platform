# Frontend and UX Architecture

## Main applications/surfaces
1. Platform administration
2. Organization/workspace administration
3. Project operations
4. Form Studio
5. End-user task inbox/form runtime
6. Reporting/dashboard
7. Domain Pack catalog/install center

## Navigation
Organization switcher -> Workspace -> Project context. User must always understand current scope.

## Form Studio
Palette, canvas/structure tree, properties panel, validation/errors, preview, version history, publish flow.

## End-user priority
My Work should be the primary landing experience for contributors: due today, overdue, returned, upcoming, waiting actions.

## Admin UX
Use dry-run/preview for destructive or broad-impact operations such as pack upgrades, bulk access changes, imports and lifecycle transitions.

## Accessibility
Keyboard navigation and visible validation errors are required for form runtime and primary admin flows.
