# Definition of Done

A feature is done only when:
- requirement/acceptance criteria are satisfied;
- authorization and tenant isolation are implemented;
- schema migration exists if needed;
- API/schema docs are updated;
- unit/integration tests pass;
- negative/error cases are tested;
- audit behavior is covered where applicable;
- logs/metrics are adequate for operations;
- no unresolved critical/high security issue exists;
- progress documentation is updated.

A phase is done only when its complete acceptance checklist passes in CI and a reproducible local setup can run the feature.
