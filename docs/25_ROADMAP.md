# Delivery Roadmap

## Phase 0 — Repository foundation
Tooling, architecture skeleton, CI, local dev, migrations, base observability.

## Phase 1 — Identity, organization, workspace, IAM
Core multi-tenant hierarchy and permission system.

## Phase 2 — Projects, departments, master data
Project context and governed reusable data.

## Phase 3 — Form engine
Builder contracts, versions, validation, runtime, attachments.

## Phase 4 — Scheduling and tasks
Schedules, occurrences, inbox, reminders.

## Phase 5 — Workflow and audit
Approvals, rejection/resubmit, immutable history.

## Phase 6 — Automation and notifications
Event-driven rules, worker infrastructure, email/in-app.

## Phase 7 — Reporting/export/import
Dashboards, export jobs, Excel migration wizard foundation.

## Phase 8 — Domain Pack framework
Manifest, registry, dependency/version/install engine, SDK validation.

## Phase 9 — Oil & Gas starter pack
Initial drilling/operations forms, master data, workflows, KPIs and mappings.

## Phase 10 — Hardening
Security, performance, backup/restore, migration validation, UAT.
